## Reuse before create

Inspect the project's component inventory before adding a new module. Extend an existing abstraction when its contract already fits.

## Verify the result

Run the relevant tests and applicable deterministic gates. A passing heuristic is not a substitute for review.

[Read the upstream documentation](https://github.com/hyperbolictonic/opencode-anti-slop#readme).
